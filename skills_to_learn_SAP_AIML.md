# 🔥 Learning Rule

> **Tutorial dekhna = padhna nahi.**

For every concept:

``` text
LEARN
  ↓
CODE
  ↓
BREAK
  ↓
DEBUG
  ↓
BUILD
  ↓
EXPLAIN
```

Examples:

### Python

If you learn loops:

**Write 20 programs yourself.**

### SQL

If you learn JOIN:

**Write your own queries on a real dataset.**

### ABAP

If you learn Internal Tables:

**Write and execute your own examples.**

### ML

If you learn Random Forest:

**Train a model on a dataset yourself.**

------------------------------------------------------------------------

# ⚠️ Important Strategy

Do **not** try to master SAP and AI/ML 50--50 forever.

Use a priority system.

### If SAP opportunity/interview comes:

``` text
70% → SAP
30% → AI/ML + Python
```

### If AI/ML opportunity/interview comes:

``` text
70% → Python / ML
30% → SAP
```

The goal is to keep **both doors open**, then go deeper into whichever
gives the strongest job opportunity.

# 🚀 One Rule for the Next 9 Months

> **Consistency beats intensity.**

You do not need to study 10 hours every day.

You need to make sure that **you do not completely stop.**

Even on a bad day:

**1 hour \> 0 hours.**

Start from zero. Build one skill at a time. Keep both SAP and AI/ML
doors open.
